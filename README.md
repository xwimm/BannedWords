# Trump Administration Banned Words Dataset

## Project Overview

This repository contains a dataset of words and phrases that were reportedly banned, discouraged, or removed from official communications during the Trump Administration (2025) published by the NY Times. The dataset aims to document linguistic restrictions in government agencies and departments as a matter of public record.

## Dataset Contents

The primary dataset is available in CSV format:
- `banned-words.csv`: Contains the full list of banned or discouraged words, along with metadata about when and where these restrictions were implemented

## Data Structure

Each entry in the dataset includes:
- **word**: The specific word or phrase that was banned or discouraged
- **category**: Categorization of the term (e.g., "DEI terminology", "Climate science", "LGBTQ+ terminology")
- **department**: The government agency or department that implemented the restriction
- **date_reported**: When the restriction was first reported
- **source**: Citation for the information
- **context**: Additional information about how the restriction was implemented

## Completeness

This dataset contains 170+ words that were reportedly restricted in various government contexts. We continue to update this information as new reports become available or as historical information is uncovered.

## Usage

This dataset is provided for:
- Historical documentation
- Research on government communication policies
- Analysis of political language restrictions
- Educational purposes about freedom of expression in government
